# Source provenance

Create one record per donor project before copied or adapted source enters the repository. Include:

- repository URL and exact commit
- source path and path-specific license
- destination path
- modifications
- copyright and notice duties
- reviewer and review date

Dependency installation alone does not count as copied source, but release license reports must include dependencies. AFFiNE requires a per-path license check. Do not copy from `packages/backend` or `packages/common/native` under the root MIT assumption. Markplane uses Apache-2.0 and needs retained notices if source is adapted.

No donor source has been copied or adapted into the Initial MVP bootstrap. The implementation uses project behavior as research and writes original narrow interfaces.
