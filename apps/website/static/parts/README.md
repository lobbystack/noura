# Interface parts

`scripts/website-screens.sh` crops these pieces from the app's real interface at 2 pixels per point. Each part has a `-light.webp` and a `-dark.webp` file of the same size.

| Part | Pixels | Shows |
| --- | --- | --- |
| `ai-approval` | 1564 × 1000 | A question about the workspace, the answer, and Noura asking before the AI creates a task |
| `plugins` | 1416 × 1048 | Settings > Plugins, with Dictation and Transcription turned off |
| `task-rows` | 878 × 450 | The Studio admin project's tasks: three upcoming and one done |
| `file-tree` | 444 × 948 | The sidebar's files, with three folders open and the Website relaunch note selected |
| `mcp` | 1416 × 794 | The MCP configuration in Settings > External tools, with its Copy button |
| `palette` | 1208 × 740 | Search for "journal", matching file names and contents |
| `calendar-day` | 1142 × 866 | Monday in the Calendar's day view, with a task due that day |
